Política de privacidad

Secretario es una aplicación de uso personal y privado. Su único usuario es su dueño, Tomás Castrillón, quien conecta sus propias cuentas de Google.

Qué datos usa

  • Google Calendar: lee los eventos para recordarlos y crea eventos cuando el dueño lo pide.
  • Gmail: solo envía correos que el dueño redactó o aprobó explícitamente. No lee la bandeja de entrada.
  • Correo de la cuenta: para identificar qué cuenta está conectada.

Cómo se guardan

Los datos se guardan en una base de datos privada a la que solo accede el servidor de la aplicación. No se venden, no se comparten con terceros y no se usan para publicidad.

El texto de los mensajes se procesa con servicios de inteligencia artificial (Anthropic y OpenAI) únicamente para entender las instrucciones del dueño.

Uso de datos de Google

El uso de la información recibida de las APIs de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions.
